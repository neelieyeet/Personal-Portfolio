BridgeGen

During my second semester at NYP, I collaborated with three teammates to develop BridgeGen, a web application aimed at bridging the generational gap between youth and the elderly in Singapore.
Built for the IT1225 Web Development module using HTML, CSS, JavaScript, SQL, and Python, the project featured a structured frontend and backend with database integration.
I was responsible for the Teach & Learn feature, which facilitates knowledge exchange between age groups, and a Digital Diary, allowing users to share weekly reflections and life milestones.
Despite it being my first experience using Python Flask, I successfully delivered a functional backend, making the project both challenging and rewarding.
